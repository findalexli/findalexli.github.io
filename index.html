Agents & evaluation

  • SWE-Together: Evaluating Coding Agents in Interactive User Sessions
    Yifan Wu*, Zhuokai Zhao, Songlin Li, Ho Hin Lee, Jiacheng Zhu, Shirley Wu, Tianhe Yu, Serena Li, Lizhu Zhang, Xiangjun Fan, Shengzhi Li*

Multimodal models

  • PushupBench: Your VLM is not good at counting pushups
    Shengzhi Li, Jiarun Chen, Karun Sharma, Jiaqi Su, Shichao Pei
    arXiv 2026paper · site · lmms-eval

    VLMs can tell what exercise you're doing but not how many reps. Counting turns out to be a good probe of temporal reasoning.

  • Video Evidence Indexing: Learning Where to Look from Video Previews for Token-Budgeted Long-Video Question Answering
    Haowen Guan, Shengzhi Li, Shichao Pei
    arXiv 2026paper

    Watch a cheap low-resolution preview first, then spend the high-resolution frame budget only where the answer is.

  • Multi-modal Preference Alignment Remedies Degradation of Visual Instruction Tuning on Language Models
    Shengzhi Li, Rongyu Lin, Shichao Pei
    ACL 2024paper · code · model

    Teaching a language model to see makes it worse at language. A small round of DPO wins it back.

  • SciGraphQA: A Large-Scale Synthetic Multi-Turn Question-Answering Dataset for Scientific Graphs
    Shengzhi Li, Nima Tajbakhsh
    arXiv 2023paper · data · code

    295K multi-turn conversations about figures in arXiv papers, generated with the paper's own text as context.
